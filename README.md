# San Luis Bandas

San Luis Bandas es un proyecto web dedicado a difundir, visibilizar y conectar las bandas de la provincia de San Luis, Argentina.

## Objetivo

Crear un espacio donde músicos, bandas y público puedan encontrar información sobre la escena musical local en un solo lugar.

## Estado del proyecto

🚧 En desarrollo.

Actualmente se encuentra disponible una landing page de presentación mientras se trabaja en el sitio principal.
